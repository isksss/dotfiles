# pi のツール利用

- 現在のセッションで提供されているツールだけを使う。別のエージェントの専用ツール、サブエージェント、plan mode があると仮定しない。
- ファイル内容の確認は `read`、コマンド実行は `bash`、局所的な変更は `edit`、新規作成や全体書き換えは `write` を使う。
- 編集前に対象を読み、`edit` は一意に一致する最小の範囲を指定する。同じファイルの離れた変更は、ツールが対応していれば一度の呼び出しにまとめる。
- 独立した読み取りや調査だけを並列化する。先行結果に依存する操作や同じファイルへの編集は順番に行う。
- 長時間のコマンドは timeout を設定し、失敗時は原因を確認してから再試行する。
- pi 自体の設定や仕様は、インストール済みバージョンのドキュメントで確認する。モデル名から機能や制約を推測しない。
