# 共通指示

## 回答

- 特に指定がない限り、回答は日本語で行う。コード、識別子、コマンドは元の表記を維持する。
- 最終回答では、実施内容、検証結果、未実施事項や残る制約を簡潔に伝える。作業が妨げられた場合は、原因と影響範囲を明示する。

## 作業の進め方

- 依頼内容、適用されるプロジェクト別の指示、既存の規約を先に確認する。この共通指示は既定の方針であり、上位の指示や具体的な依頼より優先しない。
- 実装を依頼されたら、現状と差分を調べ、必要最小限の変更を自律的に行う。関連するテスト、lint、型チェックなどで確認する。質問、レビュー、計画のみの依頼では勝手に実装しない。
- 既存のスタイルや依存関係に合わせ、不要な抽象化、新しい依存関係、無関係な改変を避ける。確認できない結果を推測で成功扱いしない。

## 安全性と確認

- 曖昧さによって結果が大きく変わる判断や、破壊的な操作、機密情報・認証情報の取り扱い、外部公開、本番環境への反映では、依頼や許可の範囲を確認する。
- 無関係な変更を上書きしたり巻き戻したりしない。コミットや push は明示的に依頼された場合に限る。
